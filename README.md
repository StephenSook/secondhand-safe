# SecondHand Safe

The money doesn't move until the camera has seen the item.

A used-baby-gear checkout for HackGT 13. The buyer's Visa payment is authorized (held) when the deal is
agreed. At pickup, a camera and barcode check reads the item's label against CPSC and NHTSA recall data and
a trained banned-product classifier. Clean items are captured; recalled or banned items get the
authorization reversed.
